# B27B Research Agents

These agents accelerate research without granting live-trading authority.

- JARVIS: independent audit layer (kept in research/jarvis.py)
- FETCH: resumable data acquisition
- FRIDAY: proposal-only operational repair planner
- VISION: approved fixed-experiment runner
- ULTRON: adversarial test planner
- EDITH: hash-chained experiment ledger
- WATCHDOG: checkpoint/stale-stage inspector
- GATEKEEPER: fail-closed research promotion controller

None of these modules authorizes brokerage access or live trading. Financial/scientific gates must not be loosened to force a pass.
